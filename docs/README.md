# Documentation

Hiwar documentation, numbered by area. [rules.md](rules.md) says what goes where and how documents are written and kept.

| Folder | Area | Holds |
| --- | --- | --- |
| [00-input-requirements](00-input-requirements/) | Input requirements | The business specification (one file) and inbound change requests |
| [01-product-requirements](01-product-requirements/) | Product requirements | Feature specs per module, UI coverage ledgers, glossary, non-functional rules, open questions |

| [03-decisions](03-decisions/) | Decisions | Decision log, decision registers, architecture decision records (ADRs) |
| [04-api-and-integrations](04-api-and-integrations/) | APIs and integrations | Platform, tutor and coach APIs; connectors, model providers, identity provider, external systems |
| [05-data](05-data/) | Data | Data model, data dictionary by domain, entity relationship diagrams |
| [06-security](06-security/) | Security | Security architecture, identities, tenancy and roles |
| [07-testing](07-testing/) | Testing | Acceptance test conventions, isolation coverage |
| [08-devops-and-deployment](08-devops-and-deployment/) | DevOps and deployment | Configuration, deployment, runbook |
| [09-releases-and-changelog](09-releases-and-changelog/) | Releases and changelog | The changelog |
| [10-project-management](10-project-management/) | Project management | Spec backlog and completed specs, task backlog, blockers, progress log |
